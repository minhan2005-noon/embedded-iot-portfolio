# Hoàng Minh Ân - Embedded & Industrial IoT Portfolio

Portfolio một trang dành cho vị trí Embedded Systems / Industrial IoT Intern.

- Website: [portfolio-cv-pi-henna.vercel.app](https://portfolio-cv-pi-henna.vercel.app)
- GitHub: [minhan2005-noon/embedded-iot-portfolio](https://github.com/minhan2005-noon/embedded-iot-portfolio)

## Nội dung

- Giới thiệu định hướng embedded, Edge AI và Industrial IoT.
- Case study MotorCare Edge AI, Face Recognition Door Lock và LATA.
- Bản đồ kỹ năng theo tầng: hardware, firmware, edge/signal và application.
- Chế độ in để lưu CV thành PDF trực tiếp từ trình duyệt.

## Chạy local

Không cần cài dependency. Chạy một static server tại thư mục này:

```bash
python3 -m http.server 4173
```

Sau đó mở `http://localhost:4173`.

## Deploy

Dự án là static site và tương thích trực tiếp với Vercel.
